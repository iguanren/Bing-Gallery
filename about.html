About Bing Gallery

A simple 4K HD wallpaper gallery

Why this project exists

为什么做这个项目

I started building websites back in 2018, knowing nothing at first — reading tutorials while writing code as I went. I ran a forum, kept a blog, and stuck with it on and off for quite a while. Later, work left me no time to keep updating them, so I archived all the blog content and rebuilt the site. For a long time I couldn't decide what it should be about — until I remembered that back in my blogging days, I liked using Bing wallpapers as the page background. Bing releases an official HD image every day, then quietly swaps it out the next day, which makes it a pain to find again. So I decided to collect the image data, archive it properly, and keep it around for a quiet browse now and then — and that's how Bing Gallery came to be.

我从 2018 年开始接触建站，那时候什么都不懂，一边查教程一边敲代码，做过论坛，也写过博客，断断续续还是坚持了挺长一段时间。后来因为工作原因，没时间继续更新，就把博客内容全部做了存档，把网站重新改版。最初我很纠结该做什么内容——直到想起以前做博客时，我喜欢拿必应美图当做网站背景。必应每天都会放出一张官方高清图片，第二天却悄悄换掉，想再找就很麻烦。于是我决定把这些图片数据收集起来，归档存好，闲暇时还能翻出来品鉴一番，于是就有了 Bing Gallery 的出现。

What this project is for

本项目有何作用

The homepage opens on today's image by default — China region first, then US — so what you see each day is always the latest. Below it, the 30 most recent images are shown as a card flow with a lightbox. Anything older is archived automatically: click Archive to browse by month. In the lightbox, you can flip through with the arrow keys or by tapping the left or right side of the screen. See one you like? Download the original straight to your device.

One thing to note: some data was lost during the maintenance upgrade, so the latest data has been re-scraped and archived since August 2026.

首屏默认是当天的图片展示，优先显示国区数据，其次是美区数据——所以你每天打开看到的，都是当天最新的图片内容。首屏下方采用卡片流灯箱的形式来展示最近的 30 张图片。更早的数据自动归档，你可以点击 Archive 按月份浏览。灯箱点开后，默认支持左右按键或者点击屏幕左右区域来翻页浏览。如果看到你喜欢的图片，可以直接”下载原图“到本地。

需要注意的是：由于维护升级过程中部分数据丢失，所以最新数据从 2026 年 8 月开始重新抓取并进行归档。

Automatic updates

自动化数据更新

This project is fully automated: GitHub Actions pulls the latest official Bing images every day, covering 15 markets worldwide, and runs a full link health check each time — dead images are replaced automatically, so nothing gets lost. Everything collected is kept in full and never deleted — in other words, every image you've seen here will stay here.

本项目实行全自动化管理，由 GitHub Actions 每天自动抓取必应官方最新的图片，抓取范围覆盖全球 15 个市场，且同步做全量链接体检，失效的图会自动补位，不会出现数据丢失。已抓取的数据本项目全量留存、永不删除——换句话说，你在本项目看到过的图片，都会一直在这里。
