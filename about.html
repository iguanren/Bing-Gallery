About Bing Gallery

A personal gallery of Bing's daily wallpapers

What is this

这是什么

A quiet personal collection. Bing posts a different official HD wallpaper every day, then quietly swaps it out the next. This site does one simple thing: keeps them, archives them, so good images are never lost.

No ads, no accounts, no pop-ups — just pictures.

一个安静的个人收藏站。必应（Bing）每天都会放一张官方高清壁纸，第二天就悄悄换掉了。这里做的事很简单：把它们留下来，归好档，让好图不会用完即丢。

全站非商业，没有广告、没有账号、没有弹窗。

What you can do

你能做什么

  • Today's pick — the homepage opens on today's wallpaper, 4K full-bleed
  • Browse the archive — hit Archive to explore by month, collected since 2019
  • View in 4K — click any wallpaper for the lightbox, arrow keys to flip through
  • Free download — 4K, watermark-free, one click, no limits
  • Night mode — toggle at the bottom right, easier on the eyes
  • 看今日大图：首屏即当天壁纸，4K 原图铺满整屏
  • 翻历史归档：点 Archive 按月份浏览，从 2019 年攒到现在
  • 看 4K 原图：点任意壁纸进灯箱，支持键盘左右翻页
  • 免费下载：4K 超清无水印，点开即存，不设任何限制
  • 夜间模式：右下角一键切换，暗光环境下眼睛舒服些

Data & updates

数据与更新

Wallpaper data is pulled daily from Bing's official API across 15 markets, updated three times a day by GitHub Actions. Every link is health-checked each run; dead images are automatically replaced, so the page never goes blank.

History is kept in full and never deleted — in other words, every image you see here will stay here.

壁纸数据每日自动抓取必应官方接口，覆盖 15 个市场，由 GitHub Actions 每天自动更新三次；同步做全量链接体检，失效的图会自动补位，页面不会开天窗。

历史数据全量留存、永不删除——换句话说，你在这里看到的每张图，都会一直在这里。
